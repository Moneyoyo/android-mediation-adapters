# Applovin Adapter

Adapter for Applovin mediation.

## Add Applovin Custom Network

Login into AppLovin. Navigate to `Mediation > Networks`. Scroll down to
`Click here to add a Custom Network`.

- Network Type: `SDK`
- Android/Fire OS Adapter Class Name: `com.moneyoyo.ads.applovinadapter.MNYYMediationAdapter`

## Configure AD Unit

- The `AppID` is the Moneyoyo App Key. This is mandatory.
- The `Placement ID` is the Moneyoyo Zone ID.
