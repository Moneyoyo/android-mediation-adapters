# AdMob Adapter

Moneyoyo custom event for AdMob mediation.

## How To

Add this library into your project, then create and configure a custom event.

Follow the
instruction [here](https://developers.google.com/admob/android/next-gen/custom-events/setup).

- This library already provide a custom event adapter for admob, so you don't need to implement your
  own `Adapter`.
- Class Name: `com.moneyoyo.ads.admobadapter.MNYYMediationAdapter`
- Parameter: `{App Key}/{Zone ID}`, for example: 69696969-d2bmfpeai6bc73e5269/42096969
